## Task 1: Make Plan B's prebuild script work in CI

**Files:**
- Modify: `site/package.json`

In CI there is no `.venv/`. The current `predev`/`prebuild` invocations of `.venv/bin/python` will fail. Fall back to `python3` when the venv isn't present.

- [ ] **Step 1: Update the scripts block in `site/package.json`**

Find the existing scripts:
```json
"predev": "cd .. && .venv/bin/python scripts/profile_to_content_jsons.py",
"prebuild": "cd .. && .venv/bin/python scripts/profile_to_content_jsons.py",
"gen:content": "cd .. && .venv/bin/python scripts/profile_to_content_jsons.py",
```

Replace with:
```json
"predev": "cd .. && $(test -x .venv/bin/python && echo .venv/bin/python || echo python3) scripts/profile_to_content_jsons.py",
"prebuild": "cd .. && $(test -x .venv/bin/python && echo .venv/bin/python || echo python3) scripts/profile_to_content_jsons.py",
"gen:content": "cd .. && $(test -x .venv/bin/python && echo .venv/bin/python || echo python3) scripts/profile_to_content_jsons.py",
"gen:vita": "cd .. && $(test -x .venv/bin/rendercv && echo .venv/bin/rendercv || echo rendercv) render site/content/profile.yaml --output-folder rendercv_output && cp rendercv_output/Aaron_D._Schroeder_CV.pdf site/public/vita.pdf",
```

The `$(test -x ... && echo X || echo Y)` shell expansion picks venv binaries when present (local dev) and falls through to PATH binaries (CI). Same pattern for `gen:vita`.

## Task 3: Add Python + RenderCV steps to the deploy workflow

**Files:**
- Modify: `.github/workflows/deploy.yml`

Insert Python setup + dependency install + RenderCV render step into the existing `build` job, BEFORE `npm run build`. The render writes to `site/public/vita.pdf` so Next.js copies it into `out/` automatically.

- [ ] **Step 1: Read the current workflow** to see exact structure

```bash
cat /Users/ads7fg/git/dads2busy.github.io/.github/workflows/deploy.yml
```

Note the existing `build:` job structure: `actions/checkout@v4` → `setup-node@v4` → `npm ci` → `npm run build` → `upload-pages-artifact@v3`.

- [ ] **Step 2: Insert the new steps**

Edit `.github/workflows/deploy.yml`. After the `actions/checkout@v4` step and BEFORE the `actions/setup-node@v4` step, insert:

```yaml
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r scripts/requirements.txt
```

After the `npm ci` step and BEFORE `npm run build`, insert:

```yaml
      - name: Render vita PDF
        run: |
          rendercv render site/content/profile.yaml --output-folder rendercv_output
          cp rendercv_output/Aaron_D._Schroeder_CV.pdf site/public/vita.pdf
```

The full updated `build:` job should now have these step ordering:
1. `actions/checkout@v4`
2. `actions/setup-python@v5` (NEW)
3. `pip install -r scripts/requirements.txt` (NEW)
4. `actions/setup-node@v4`
5. `npm ci` (working-directory: site)
6. Render vita PDF (NEW — runs from repo root, not site/)
7. `npm run build` (working-directory: site) — its `prebuild` now uses python3 from PATH
8. `actions/upload-pages-artifact@v3`

The render step's working directory defaults to the repo root (no `working-directory: site`), so the relative paths `site/content/profile.yaml`, `rendercv_output/`, and `site/public/vita.pdf` all resolve correctly.
